# Decisiones de arquitectura

Los ADR registran decisiones aceptadas y sus consecuencias. No son un backlog ni una
lista de ideas. Una decisión nueva usa el siguiente número disponible y no reescribe un
ADR aceptado: lo reemplaza con otro que lo referencia.
