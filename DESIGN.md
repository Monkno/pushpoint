# Dirección visual de PushPoint

Fuente: brief de marca entregado por el propietario.

## Design Read

Sitio institucional B2B para startups y PyMEs, con una voz técnica, cercana y directa. La interfaz usa un lenguaje minimalista en navy, negro y morado, con diales `ENERGY 2 / RHYTHM 2 / MOTION 1`.

## Identidad

- La marca se presenta como texto hasta contar con un logo aprobado.
- El foco está en la capacidad de convertir necesidades de negocio en software mantenible.
- El tono evita promesas exageradas, jerga innecesaria y claims sin evidencia.

## Decisiones visuales

- Color: navy y negro forman una base sobria; el morado se reserva para acciones, foco y pequeñas señales de jerarquía.
- Tema: el modo oscuro sigue la paleta principal indicada en el brief y mantiene una sola experiencia durante esta fundación.
- Tipografía: la pila del sistema reduce carga y mantiene lectura familiar; el monoespaciado aparece solo en índices del proceso para aportar precisión técnica.
- Layout: la home combina una propuesta de valor con el ciclo real de trabajo, sin tarjetas decorativas ni secciones de plantilla.
- Espaciado: una escala fluida reduce el espacio vertical en teléfonos y lo amplía gradualmente hasta escritorio.
- Radios: las superficies usan radios pequeños o medios; el radio completo se reserva para la acción principal.
- Elevación: solo el menú móvil usa sombra porque se superpone al contenido.
- Movimiento: las transiciones responden a hover, foco, apertura y cierre; no hay animaciones automáticas.
- Motif: la secuencia numerada de cuatro etapas representa el acompañamiento desde definición hasta mantenimiento.

## Contenido pendiente

Las páginas todavía no desarrolladas deben presentarse como tales. Ninguna CTA puede prometer un formulario, caso, servicio o política que aún no exista.
